# MIcroproyecto2_Implementaci-n_cluster_Kubernetes-_Azure
En el microproyecto desplegamos un cluster de Kubernetes en Azure utilizando AKS con al menos dos nodos. Luego desplegamos una aplicación de clasificación de imágenes en el cluster y otra aplicación adicional. También utilizamos herramientas de monitoreo para observar el estado de los recursos y las aplicaciones.
